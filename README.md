# 二〇二六臺北：市長政見格鬥

一場可在瀏覽器裡玩的 2D 格鬥原型，氣氛來自選舉之夜的廣場、市府與辯論臺。

周晚燈（夜市共好聯盟）想把夜市開到清晨。沈靜川（靜川市政社）想讓巷子在十一點恢復安靜。兩人約在虛構的市府廣場，用三個回合把吵不完的規則打完。

角色、黨名、主張都是為這個諷刺短篇發明的，與真實人物、政黨、選舉無關。這不是競選文宣。

## 怎麼執行

需要一個能開本機網頁的現代瀏覽器。不必安裝遊戲引擎，也不必建置。

在這個資料夾啟動一個小伺服器：

```bash
python3 -m http.server 8080
```

然後打開 [http://localhost:8080](http://localhost:8080)。

也可以直接用瀏覽器開啟 `index.html`。畫面、操作與音效都不依賴外網。

## 怎麼玩

開場是幾段短文，按 **Enter** 或 **空白鍵** 前進，**Backspace** 回到上一段。看完之後選對戰方式：

- **1** 或按鈕：雙人同鍵盤
- **2** 或按鈕：對上電腦（電腦擔任右側）
- **R**：交換左右角色
- **Enter**：開始這一場

預設左側是周晚燈、右側是沈靜川。交換之後，左側仍用 1P 的按鍵。

### 1P（左側）

| 按鍵 | 動作 |
| --- | --- |
| A / D | 左右移動。往對手的反方向走，同時會防禦 |
| W | 跳。跳起來可以躲過多數站立攻擊 |
| S | 原地防禦 |
| J | 輕攻 |
| K | 重攻 |
| L | 必殺（能量集滿才能放） |

### 2P（右側）

| 按鍵 | 動作 |
| --- | --- |
| ← / → | 左右移動。往對手的反方向走，同時會防禦 |
| ↑ | 跳 |
| ↓ | 原地防禦 |
| 1（或小鍵盤 1） | 輕攻 |
| 2（或小鍵盤 2） | 重攻 |
| 3（或小鍵盤 3） | 必殺 |

對電腦時，右側不吃鍵盤。

**Esc** 暫停。暫停中再按 **Esc** 繼續，按 **Q** 回到開頭。畫面下方的「音效」可以關掉合成音。

## 規則與招式

三戰兩勝。每一回合 60 秒，雙方各 100 點生命。生命歸零的一方輸掉該回合；時間到則生命較高的一方取勝。同時倒下或生命相同，該回合重賽，不計勝場。

能量在打中、被打中時上升。集滿之後才能放必殺。必殺被防住仍會削去少量生命，輕攻與重攻被防住不會扣血。

打中之後可以取消接招：輕攻可接重攻或必殺，重攻可接必殺。空揮接不出去。攻擊只在地上發動。

兩個人的招不一樣。

- 周晚燈：步調較快。輕攻「攤販拍」距離短，重攻「鐵鍋橫掃」範圍大，必殺「深夜辣椒」射出一道辣椒油。
- 沈靜川：手比較長、動作稍慢。輕攻「指標點名」用來點距離，重攻「卷宗砸擊」較重，必殺「準時蓋章」向前衝刺。

## 原型範圍

這一版只有開場與一場對戰。沒有網路對戰、沒有連招表練習模式、沒有更多角色。電腦會走近、出招、偶爾防禦，不會讀你的操作。角色是向量畫的卡通，不是逐格動畫。音效是瀏覽器即時合成的，沒有配樂。傷害與幀數還沒有經過長期調整。
